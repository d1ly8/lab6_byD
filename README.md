- `app.js` — validation, events, fetch, grading, sorting, and navigation
- `students.json` — student records

## How to run

The project uses `fetch()`, so open the folder with VS Code Live Server, or run a local HTTP server. Do not open the HTML file directly with a `file://` URL.
